Browser demo

CPPWRF-Web provides a WebAssembly model demo and a separate forecast interface.

Run an idealized case

CPPWRF runs in double precision in WebAssembly. Choose the 2D squall line (em_squall2d_x) or the 3D supercell (em_quarter_ss) and watch vertical sections of potential-temperature perturbation, vertical velocity and rainwater.

At the end, the demo checks hashes for every wrfout variable and output time against native CPU FP64 CPPWRF. The project reports matching hashes and byte-identical files for both cases. This build uses CPPWRF v1.0.0.

  • Open WebAssembly demo

Explore the forecast site

The Turkish-language forecast interface displays forecasts on a WebGL2 map with a meteogram and Skew-T. It can run real-data CPPWRF forecasts through a local server, and the public page shows sample forecasts when that server is unavailable.
