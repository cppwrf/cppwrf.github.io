Install CPPWRF

Build from source, use a release tarball for your build flavour, or use a container. The source build needs a C++20 compiler, CMake 3.24 or later, OpenMP and NetCDF-C headers. The tools use Python 3 with NumPy and netCDF4.

For CUDA builds, the minimum is CUDA Toolkit 12.1 and an NVIDIA GPU with compute capability 7.0. Check the install guide for toolkit requirements on your GPU and host compiler.

Build and test CPU FP64

From the v1.4.0 source tree with the prerequisites installed.

cmake -S . -B build-cpu \
  -DCMAKE_BUILD_TYPE=Release \
  -DCPPWRF_ENABLE_CUDA=OFF \
  -DCPPWRF_DOUBLE=ON
cmake --build build-cpu -j "$(nproc)"
cmake --install build-cpu --prefix "$HOME/cppwrf"
export PATH="$HOME/cppwrf/bin:$PATH"
"$HOME/cppwrf/share/cppwrf/examples/selftest/run.sh" cpu-fp64

First real-data forecast

  1. Run WPS on GFS inputs to produce the met_em files.
  2. Place the met_em files and namelist.input in a run directory. Match num_metgrid_levels and num_land_cat to the inputs, then run cppwrf-realexe to write wrfinput and wrfbdy.
  3. Link the runtime tables from WRF v4.8.0’s run/ directory. Check the options with cppwrf-check namelist.input and run cppwrf-wrf --mode cpu-fp64 to write wrfout.
  4. Run the quick-start plot.py example to make a map from the output.
